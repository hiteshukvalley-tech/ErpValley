# ERPVALLEY client

The public website: React 19, Vite, TypeScript, Tailwind CSS 4 and React Router 7.

```bash
npm install
npm run dev        # http://localhost:5300 (/api is proxied to the server on port 5301)
npm test           # Vitest + Testing Library
npm run lint       # oxlint
npm run build      # typecheck + production build into dist/
npm run preview    # serve dist/ on http://localhost:4300
```

See the [project README](../README.md) for the full structure, build steps and API.
